# Approved Design References

These files preserve the approved visual direction for the Astro rebuild.

- `mockups/article-family-approved.html` — article layout, approved with the ListWithMe example active.
- `mockups/index-family-approved.html` — shared indexes, approved with the Blog view active and the title `Things I've written.`
- `mockups/detail-family-approved.html` — shared dossier layout, approved with the My App / ListWithMe view active.

The index and detail files include preview-only switches for their variants. They are design references, not production templates.

The mockups use imagery from the frozen Vite homepage running on port 4173. See the main design specification for the source allowlist, checksums, states, and viewport sizes.

The production implementation must compare each page family against these sources at 1586 × 992, 1024 × 768, and 390 × 844.
